# AWS CIS Scanner

> Scans AWS accounts for security misconfigurations against CIS Benchmark controls,
> emitting severity-rated findings with remediation guidance.

🚧 **Work in progress** — building toward S3, IAM, and EC2 checks.

## Why
Cloud misconfiguration — public storage, over-permissive identity, open network
ingress — is a leading cause of real-world breaches. This tool audits for that
class of issue and maps each finding to a CIS control.
